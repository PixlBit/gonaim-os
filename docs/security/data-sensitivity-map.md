# Data Sensitivity Map — GONAIM//OS

> **Source:** Master Blueprint §30، Expansion §23.2، §4.6
> **الحكم:** التصنيف يحدث **عند الاستقبال**، قبل أي تخزين أو استنتاج أو نداء نموذج.
> لا توجد بيانات "غير مصنفة" داخل النظام. الافتراضي عند الشك هو الأعلى حماية.

---

## 1. المناطق الست

| المنطقة | التعريف | التخزين | يغادر الجهاز؟ | Embedding | Retention افتراضي |
| --- | --- | --- | --- | --- | --- |
| `open` | بيانات عادية داخل النظام | Postgres عادي | ✅ نعم | ✅ سحابي | دائم حتى الحذف |
| `private` | تحتاج جلسة موثقة | Postgres + RLS | ✅ نعم | ✅ سحابي | دائم حتى الحذف |
| `sensitive` | مال، علاقات خاصة، وثائق | حقول مشفرة | ⚠️ ملخص مُنقّح فقط | 🔒 محلي فقط | 12 شهرًا ثم مراجعة |
| `vaulted` | Local-only أو hardware-backed | جهاز غنيم فقط | ❌ **أبدًا** | 🔒 محلي فقط | يدوي فقط |
| `ephemeral` | تنتهي بانتهاء الجلسة | ذاكرة فقط، لا قرص | ❌ لا | ❌ لا | نهاية الجلسة |
| `never_observe` | قائمة سوداء صريحة | **لا يُخزَّن إطلاقًا** | ❌ لا | ❌ لا | لا وجود |

> `sensitive` يعني: **الملخص** قد يصعد للسحابة بعد redaction، لكن النص الخام لا يصعد.
> `vaulted` يعني: **لا شيء** يصعد — ولا حتى متجه دلالي (راجع ADR-0005).

## 2. تصنيف كل مصدر بيانات

### 2.1 المتصفح — LENS

| البيان | المنطقة | ملاحظة |
| --- | --- | --- |
| Domain + URL + Title | `private` | Ambient mode |
| مدة التركيز على تبويب | `private` | تجميعي بعد 30 يومًا |
| محتوى الصفحة عند Focus | `private` | لا يُخزَّن إلا عند `Pin` |
| رسالة ChatGPT/Claude **بعد الإرسال** | `private` | ملخص + intent فقط، لا DOM كامل |
| ما يُكتب أثناء الكتابة | `never_observe` | **لا keylogging — قاعدة صلبة** |
| حقول `password` / `payment` | `never_observe` | تُستبعد على مستوى الـselector |
| صفحات بنوك وبوابات دفع | `never_observe` | تعطيل تلقائي بالـdomain |
| الوضع الخفي (incognito) | `never_observe` | الإضافة معطلة كليًا |

### 2.2 الملفات والسحابة

| البيان | المنطقة |
| --- | --- |
| Drive metadata لمجلد مختار | `private` |
| Drive thumbnails | `private` |
| محتوى ملف كامل | `private` عند Pin، وإلا لا يُجلب |
| مجلدات Windows في Allowlist — أسماء وتغيّرات | `private` |
| ملفات خارج Allowlist | `never_observe` |
| فواتير وعقود (Gmail labels محددة) | `sensitive` |
| باقي البريد | `never_observe` |

### 2.3 الشخصي والحساس

| البيان | المنطقة | ملاحظة |
| --- | --- | --- |
| الهوية الأساسية (اسم، مهنة، مدينة) | `open` | |
| التفضيلات البصرية والذوق | `open` | |
| Portfolio وأعمال منشورة | `open` | |
| السيولة والفواتير والاشتراكات | `sensitive` | جلسة أقصر + تأكيد إضافي |
| الأشخاص والعلاقات | `sensitive` | **لا Person Score إطلاقًا** |
| محتوى رسائل خاصة | `never_observe` | إلا بموافقة صريحة لكل محادثة |
| بيانات الصحة والـWellbeing | `vaulted` | يدوي فقط، لا تشخيص، اختياري بالكامل |
| المستندات الرسمية (جواز، إقامة، عقود) | `vaulted` | |
| كلمات المرور والتوكنز والمفاتيح | `never_observe` | redaction محلي إلزامي قبل أي نداء |
| الموقع الجغرافي | `private` / `sensitive` | حسب الدقة: City / Area / Exact / Off |
| الكاميرا والميكروفون | `ephemeral` | جلسات صريحة فقط، لا استماع دائم |

## 3. قواعد الـRedaction

تُطبَّق **مرتين**: في العميل قبل الإرسال، وفي الـWorker قبل نداء النموذج (ADR-0006).

| النمط | الإجراء |
| --- | --- |
| `sk-…`, `ghp_…`, `AIza…`, JWT | استبدال بـ`[REDACTED_SECRET]` |
| أرقام بطاقات (Luhn) | `[REDACTED_CARD]` |
| IBAN / أرقام حسابات | `[REDACTED_ACCOUNT]` |
| أرقام هوية/إقامة/جواز | `[REDACTED_ID]` |
| أرقام هواتف | `[REDACTED_PHONE]` مع إبقاء آخر رقمين للسياق |
| عناوين بريد لأشخاص آخرين | `[PERSON_<hash>]` مستقر عبر الجلسات |

**الـredaction لا تُبطَّل بإعداد مستخدم.** ما يُنقَّح لا يصل للنموذج أصلًا.

## 4. الأربعة مفاتيح لكل Sense

كل مصدر يحمل أربعة مفاتيح مستقلة، لا مفتاحًا واحدًا (Expansion §4.6):

| المفتاح | السؤال |
| --- | --- |
| `can_observe` | هل يرى؟ |
| `can_remember` | هل يحتفظ بما رأى؟ |
| `can_infer` | هل يبني استنتاجًا؟ |
| `can_act` | هل يقترح أو ينفذ؟ |

مثال عملي مطلوب دعمه: صفحة بنكية بـ`observe = on` و`remember = off` و`infer = off`.
يرى الرصيد للحظة ليجيب سؤالًا، ولا يبقى منه أثر.

### الإعدادات الافتراضية عند التثبيت

| المصدر | observe | remember | infer | act |
| --- | --- | --- | --- | --- |
| Browser Ambient | ✅ | ✅ | ✅ | ❌ |
| Browser Focus | ❌ حتى التفعيل اليدوي | ✅ | ✅ | ❌ |
| Drive (مجلدات مختارة) | ✅ | ✅ | ✅ | ❌ |
| Gmail | ❌ | ❌ | ❌ | ❌ |
| Money | ✅ يدوي | ✅ | ❌ | ❌ |
| Location | ❌ | ❌ | ❌ | ❌ |
| Camera / Mic | ❌ | ❌ | ❌ | ❌ |
| Wellbeing | ❌ | ❌ | ❌ | ❌ |

## 5. Retention

| نوع البيانات | الافتراضي | بعد المدة |
| --- | --- | --- |
| Raw browser activity | 30 يومًا | تجميع إحصائي، حذف الخام |
| Page text snapshots | لا يُخزَّن | إلا عند Pin أو Focus policy |
| Summaries + intents | طويل المدى | مع المصدر دائمًا |
| Events | 24 شهرًا | تجميع ثم أرشفة |
| Memories | حتى الحذف اليدوي | مع مراجعة دورية للـ`contested` |
| Credentials | حتى الإلغاء | مشفرة، منفصلة |
| Audit log | 12 شهرًا | قابل للتمديد بقرار المستخدم |
| Wellbeing | يدوي فقط | لا حذف تلقائي، لا احتفاظ تلقائي |

## 6. Kill Switches

| المفتاح | الأثر | زمن السريان |
| --- | --- | --- |
| Browser Blackout | إيقاف LENS فورًا | فوري |
| Cloud Blackout | قطع كل الـconnectors | فوري |
| Agent Blackout | إيقاف كل الوكلاء والأفعال المعلقة | فوري |
| Memory Freeze | قراءة فقط — لا ذاكرة جديدة | فوري |
| Local-only mode | لا نداءات سحابية إطلاقًا | فوري |
| Emergency revoke | إلغاء كل الـOAuth tokens | فوري + غير قابل للتراجع |

**شرط قبول:** Blackout يوقف الـingestion فورًا، لا "عند الحدث التالي".
الـcaptures المحلية غير المرسلة تبقى على الجهاز وتُعلن في الواجهة.

## 7. Proof of Forgetting

بعد أي حذف، يُعرض إيصال — لا كلمة `Done`:

```text
PURGE RECEIPT
Deleted:            14 events · 3 memories · 1 asset reference
Retained:           2 summaries (derived, source now unlinked)
Outside our reach:  original file still in Google Drive
Action required:    delete from Drive manually to complete
```

**ممنوع** عرض `Forgotten` إذا بقيت ذاكرة مشتقة خفية.

## 8. حدود لا تتغير بإعداد

هذه ليست إعدادات افتراضية — هي حدود المنتج (Expansion §43):

- ❌ لا اختراق حسابات ولا تسجيل دخول نيابة عن المستخدم.
- ❌ لا تتبع أشخاص آخرين دون علمهم.
- ❌ لا تسجيل غرف أو مكالمات سرًا.
- ❌ لا تقييم قيمة البشر ولا Person Score.
- ❌ لا keylogging تحت أي وضع.
- ❌ لا بيانات بنكية أو صحية بلا Scope صريح ومحدود.
- ❌ لا شراء ولا دفع ولا نشر ولا إرسال تلقائي.
