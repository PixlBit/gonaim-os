# ADR-0009 — External-first: الأصل يبقى في مصدره

- **Status:** Accepted
- **Date:** 2026-08-22
- **Source:** Master Blueprint §23.1، §5.6

## السياق

النظام يلمس Drive وPhotos وInstagram وGitHub وملفات محلية. نسخ كل ذلك إلى خادم
جديد يعني: تكلفة تخزين، تكرار، تعارض نسخ، ومسؤولية أمنية عن نسخة ثانية من حياة
كاملة — بلا مقابل حقيقي.

## القرار

**External-first, metadata-rich, selectively cached.**

المحفوظ محليًا لكل أصل خارجي:

```yaml
external_id:    "معرّف المزود"
canonical_url:  "الرابط الأصلي — يفتح في مكانه"
metadata:       { mime, size, dimensions, created_at, modified_at }
thumbnail:      "وفق سياسة المصدر فقط"
checksum:       "إن أمكن — لكشف التغيير والتكرار"
tags, relations, user_note, ai_summary
last_sync_state: { synced_at, source_health }
```

النسخة الكاملة تُجلب **فقط** عند:
- تثبيت صريح (`Pin`)، أو
- وجود الملف داخل folder مصرح بتحليله، أو
- طلب مباشر من غنيم.

### شرط القبول الصارم

**حذف مصدر خارجي أو قطع اتصاله لا يكسر النظام.** العُقدة تبقى، وتتحول حالتها
إلى `source_unavailable` مع آخر metadata معروفة وتاريخها. لا شاشة خطأ، ولا فقدان علاقات.

### التصدير

`Export my mind` يخرج JSON + Markdown + CSV، مع الـcanonical URLs محفوظة —
حتى لو مات المنتج، تبقى الخريطة قابلة للقراءة بشريًا.

## النتائج

**إيجابية** — تخزين أقل، مخاطرة أمنية أقل، لا مزامنة ثنائية الاتجاه (أكبر مصدر للتعقيد في هذه الفئة من المنتجات)، وسيادة حقيقية على البيانات.

**سلبية** — العمل دون اتصال محدود: metadata وthumbnails فقط. الوسائط الأصلية تحتاج المصدر. مقبول ومُعلن.

## البدائل المرفوضة

| البديل | سبب الرفض |
| --- | --- |
| نسخ كل شيء إلى R2/Supabase | تكلفة ومسؤولية أمنية بلا فائدة مقابلة |
| مزامنة ثنائية الاتجاه | تعارضات لا تنتهي، وخطر تعديل أو حذف مصادر حقيقية |
| روابط فقط بلا metadata | يمنع البحث والربط دون اتصال — يقتل ATLAS وTime Mirror |
