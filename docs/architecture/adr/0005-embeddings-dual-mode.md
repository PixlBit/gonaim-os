# ADR-0005 — Embeddings بوضعين

- **Status:** Accepted
- **Date:** 2026-08-22
- **Source:** Master Blueprint §28.4

## السياق

Anthropic لا تقدم نموذج embeddings خاصًا بها
([Embeddings guide](https://docs.anthropic.com/en/docs/build-with-claude/embeddings)).
والمحتوى هنا **ثنائي اللغة** — عربي وإنجليزي في نفس الجملة أحيانًا — فأي نموذج
إنجليزي فقط سيفشل في نصف البيانات.

وفي نفس الوقت: بعض النصوص لا يجوز أن تغادر الجهاز أصلًا (`vaulted`, `sensitive`).

## القرار

وضعان، **يُختاران لكل `sensitivity zone` وليس للنظام كله**:

| الوضع | المحرك | يغطي | متى |
| --- | --- | --- | --- |
| **Convenience** | مزود embeddings سحابي متعدد اللغات | `open`, `private` | افتراضي في MVP |
| **Privacy** | نموذج محلي عبر Windows Companion (RTX 4090) | `sensitive`, `vaulted` | إلزامي لهذه المناطق |

**القاعدة الصلبة:** ما دام Windows Companion غير مبني (قبل V2)، فإن المحتوى المصنف
`sensitive` أو `vaulted` **لا يُولَّد له embedding إطلاقًا**. يبقى قابلًا للبحث
بـkeyword محلي فقط. لا نرسله للسحابة "مؤقتًا".

كل صف embedding يحمل `model_id` و`dim` و`generated_at` حتى تكون إعادة التوليد
عند تغيير النموذج عملية هجرة واضحة، لا كارثة صامتة.

## النتائج

**إيجابية** — منطقة `vaulted` تحافظ على معناها حرفيًا: لا شيء منها يغادر الجهاز، ولا حتى كمتجه.

**سلبية** — البحث الدلالي في المناطق الحساسة معطّل حتى V2. مقبول ومُعلن في الواجهة بنص صريح، لا بصمت.

## البدائل المرفوضة

| البديل | سبب الرفض |
| --- | --- |
| مزود سحابي واحد لكل شيء | متجه النص الحساس يسرّب معناه؛ يُبطل تصنيف `vaulted` |
| نموذج محلي فقط | يمنع العمل من أي جهاز غير الـworkstation |
| نموذج إنجليزي فقط | يفشل على المحتوى العربي — نصف بيانات غنيم |
