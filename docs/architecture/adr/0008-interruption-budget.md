# ADR-0008 — بوابة تسجيل وميزانية مقاطعة

- **Status:** Accepted
- **Date:** 2026-08-22
- **Source:** Master Blueprint §12.2، §5.4؛ Expansion §10.1، §22

## السياق

نظام يرى كل شيء يستطيع أن يتكلم طوال الوقت. لو تكلم طوال الوقت، يُطفأ خلال أسبوع.
المخاطرة المسجلة في §39: *"Notification overload → تجاهل النظام"*.

## القرار

لا يصل أي اقتراح إلى الشاشة قبل المرور ببوابتين متتاليتين.

### البوابة الأولى — التسجيل

```text
relevance = 0.30 × goal_match
          + 0.25 × urgency
          + 0.20 × novelty
          + 0.15 × evidence_strength
          + 0.10 × timing_fit
          - interruption_cost
```

| النتيجة | السلوك |
| --- | --- |
| `< 0.45` | حفظ صامت — يظهر في `Below signal threshold` فقط |
| `0.45 – 0.69` | Signal Inbox |
| `0.70 – 0.84` | Nudge داخل NOW أو Side Panel |
| `≥ 0.85` | إشعار نظام |
| `risk = critical` | Interrupt يتجاوز الحد — **بشرط دليل قوي، لا استنتاج** |

### البوابة الثانية — الميزانية

**3 مقاطعات ذكية يوميًا** افتراضيًا. عند النفاد، كل ما هو أقل من `critical`
ينزل درجة إلى Signal Inbox بدل الاختفاء.

`Quiet Hours` سياقية وليست ساعات ثابتة فقط: تبدأ تلقائيًا عند
full-screen edit، render review، مكالمة، أو قيادة.

### Regret Threshold

المقاطعة لا تحدث لأن الشيء "مهم عمومًا"، بل لأن:

```text
P(يندم غنيم على تفويته) × كلفة التفويت  >  كلفة مقاطعة السياق الحالي
```

وكل Interrupt يعرض تقدير الطرفين. هذا يجعل الحكم قابلًا للنقاش والتصحيح.

### Silence كقرار

`Silence` نمط أول الدرجة في CORTEX (Expansion §6)، وليس غياب فعل.
النظام يسجل `decided_to_stay_silent` مع السبب — وهذه بيانات تدريب للـranking.

## النتائج

**إيجابية** — النظام يصبح هادئًا بالتصميم لا بالصدفة. مؤشر `Useful Signal Rate ≥ 60%` يصبح قابلًا للقياس فعلًا.

**سلبية** — سيفوت النظام أشياء مفيدة في البداية بينما الـranking غير مضبوط. مقبول: تفويت أفضل من ضجيج. الـfeedback (`Useful / Too late / Already knew / Wrong / Never this type`) هو ما يضبط الأوزان.

## البدائل المرفوضة

| البديل | سبب الرفض |
| --- | --- |
| ترتيب زمني بلا تسجيل | يتحول لخلاصة أخبار — النموذج الذي ترفضه §2.3 صراحة |
| ترك النموذج يقرر المقاطعة | لا حد أعلى، ولا قابلية للتدقيق أو المعايرة |
| إشعارات فورية للكل مع إمكانية الكتم | الضرر يقع قبل الكتم؛ الثقة تُفقد مرة واحدة |
