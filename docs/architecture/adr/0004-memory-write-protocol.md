# ADR-0004 — لا كتابة مباشرة للذاكرة

- **Status:** Accepted
- **Date:** 2026-08-22
- **Source:** Master Blueprint §13.4، Expansion §5.2، §5.3

## السياق

لو سُمح للنموذج بكتابة `memories` مباشرة، تتحقق أخطر ثلاث مخاطر في الوثيقة دفعة واحدة:
ذاكرة كاذبة (§24.3)، استبدال صامت لحقيقة صحيحة، وحبس غنيم داخل نسخة قديمة من نفسه (§24.7).

## القرار

`memories` **لا تُكتب من نداء نموذج**. المسار الوحيد:

```text
observation → memory_candidates → [7 بوابات] → memories
```

البوابات السبع، بالترتيب، وكل واحدة قادرة على الرفض:

| # | البوابة | الفشل يعني |
| --- | --- | --- |
| 1 | Candidate extraction | لا معلومة قابلة للاستخلاص |
| 2 | Source binding | **رفض إلزامي** — بلا `source_event_id` لا توجد ذاكرة |
| 3 | Deduplication | دمج مع ذاكرة قائمة ورفع `evidence_count` |
| 4 | Contradiction check | إنشاء `Conflict Frame` بدل الاستبدال |
| 5 | Sensitivity classification | تحديد المنطقة قبل التخزين |
| 6 | Confidence assignment | رقم + سبب نصي |
| 7 | Auto-accept / Review queue | حسب `kind` |

### قاعدة الـauto-accept

| نوع الذاكرة | السلوك |
| --- | --- |
| `preference`, `procedural`, `episodic` | auto-accept عند `confidence ≥ 0.80` ومصدرين مستقلين |
| `semantic` | auto-accept عند `confidence ≥ 0.90` |
| `identity`, `money`, `relationship`, `sensitive` | **review queue دائمًا** — لا استثناء |

### Conflict Frame

عند تناقض، لا يُستبدل القديم. يُنشأ صف في `memory_conflicts` يحمل:
المعلومتين، توقيت كل منهما، مصدر كل منهما، وسؤالًا صريحًا:
*هل تغيّر رأيك، أم أن أحد المصدرين خاطئ، أم أن التناقض زمني طبيعي؟*
حتى الإجابة، القديمة `active` والجديدة `contested` — والواجهة تعرض الاثنتين.

### النسيان

`Forget` فعلي وقابل للتدقيق. عند الحذف يُعرض **Purge Receipt**:
ما حُذف، ما بقي لأن مصدره خارجي، وما يحتاج حذفًا من مزود آخر.
**ممنوع** عرض كلمة `Forgotten` إذا بقيت ذاكرة مشتقة خفية (§23.4 في Expansion).

## النتائج

**إيجابية** — كل صف في `memories` له مصدر ومسار مراجعة. `Why do you know this?` تُجاب من القاعدة، لا من تخمين.

**سلبية** — الذاكرة تنمو أبطأ، وتحتاج مراجعة بشرية دورية. هذه تكلفة مقصودة: ذاكرة صغيرة صحيحة أفضل من ذاكرة كبيرة ملوثة.

## البدائل المرفوضة

| البديل | سبب الرفض |
| --- | --- |
| كتابة مباشرة مع مراجعة لاحقة | التلوث يحدث فورًا، والمراجعة اللاحقة لا تحدث عمليًا |
| ثقة النموذج كمعيار وحيد | النموذج واثق بالتساوي في الصحيح والمختلق |
| استبدال القديم بالأحدث دائمًا | يمسح تاريخ تغيّر الرأي، وهو معلومة ثمينة بذاته |
