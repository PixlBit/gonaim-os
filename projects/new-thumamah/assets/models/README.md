# نماذج ثلاثية الأبعاد

ضع هنا ملفات `.glb` بالأسماء التالية، ويلتقطها التطبيق تلقائيًا ويستبدل بها العناصر المولّدة برمجيًا.
أي ملف غير موجود يبقى على البديل المولّد، فلا ينكسر المشهد.

## شروط الملف

- صيغة **GLB** واحدة تتضمن الخامات (أو GLTF مع ملفاته في نفس المجلد).
- **بلا أرضية** تحت المجسم، والقاعدة عند مستوى الصفر.
- الاتجاه: الواجهة نحو **-Z**. لو كان الاتجاه مختلفًا يُصحَّح من `yaw` في `src/models.js`.
- المقاس لا يهم: التطبيق يعيد تحجيم النموذج إلى الارتفاع الحقيقي في الجدول أعلاه.
- يُفضّل ≤ 2 م.ب للملف الواحد وخامات ≤ 1024 بكسل، لأن النسخة المدمجة لها سقف حجم.

## الحقوق

سجّل مصدر كل نموذج ورخصته في `CREDITS.md` بجانب هذا الملف قبل النشر.

## منصة التصوير المرجعي (tools/turntable.html)

لتوليد بديل عالي الجودة لعنصر موجود، صوّر العنصر الحالي أولًا ثم استخدم اللقطة مرجعًا:

```
node tools/serve.cjs &
NODE_PATH=/opt/node22/lib/node_modules NT_VIEWS=hero node tools/shoot-props.mjs tent dome suv
```

تُحفظ اللقطات في `shots/props/<اسم>-<زاوية>.png`. الزوايا المتاحة:
`hero` (ثلاثة أرباع، للمرجع البصري) و`front`/`left`/`back`/`right` (متعامدة، لمدخلات النماذج متعددة الرؤى).

فائدة المرجع أنه يثبّت النسب والبصمة الأرضية المطابقة للمخطط العام،
فلا يعود شكل النموذج المولَّد رهن الصدفة.
