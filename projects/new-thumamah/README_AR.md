# نيو ثمامة — استوديو المخطط ثلاثي الأبعاد

تصور مكاني تفاعلي مبني على **الملف المعتمد**: ممر خدمات (وقود وبنشر وبقالة) ← بوابة ورسوم ←
إدارة وسكن عمال ومواقف 1000 سيارة ← مخيمات وكشتات ← أطفال واسطبل خيل وفود تراك شعبية ←
وأعلى الجبل: العزم والتطعيس والرماية ومطعم ولاونج ودومز ومواقف VIP بإطلالة على المخيم كامل.

العرض ثلاثي الأبعاد حقيقي (WebGL) بتضاريس وجبل وكثبان، وشمس فيزيائية وظلال،
**وصورة الموقع الفعلية مفروشة على الأرض**.

## التشغيل

```bash
node tools/serve.cjs        # أو: npm start
# ثم افتح http://127.0.0.1:4173
```

يمكن أيضًا فتح `index.html` مباشرة بالنقر المزدوج؛ الملفات تُحمَّل كنصوص برمجية عادية بلا وحدات ES، فتعمل من القرص.
صور الأقمار الصناعية تحتاج اتصالًا بالإنترنت؛ عند تعذرها يظهر سطح صحراوي بديل ويُعلَن ذلك على الشاشة.

## الحالات الثلاث

| الحالة | ما تعرضه |
|---|---|
| **الخريطة** | المخطط مثبت جغرافيًا فوق صور Esri أو خريطة OpenStreetMap، مع تكبير حر إلى محيط الموقع |
| **ثري دي** | النموذج الكامل: تضاريس مستوية بصورة الموقع، مبانٍ ومظلات وخيام وقباب، شمس وظلال ونهار وغروب وليل |
| **مسقط** | مسقط علوي متعامد بالشمال لأعلى، مع تلوين استخدامات الأرض |

## التحكم

| الإدخال | النتيجة |
|---|---|
| سحب | تدوير حول نقطة النظر (مع قصور ذاتي وتخميد) |
| Shift + سحب · زر أيمن · إصبعان | تحريك أفقي |
| عجلة الفأرة · تقريب بإصبعين | تكبير **نحو موضع المؤشر** |
| نقرة مزدوجة | طيران منعّم إلى الموضع |
| نقرة | اختيار المنطقة وعرض بطاقتها |
| `W A S D` / الأسهم | تحريك (مع `Shift` أسرع) |
| `Q E` | تدوير · `R F` رفع وخفض زاوية النظر |
| `1` `2` `3` | تبديل بين الخريطة والثري دي والمسقط |

زر **جولة** يشغّل مسارًا سينمائيًا يتبع تسلسل الفيلم في الخطة التسويقية: وصول ← خيل ← درب ← أطفال ← غروب ← مخيم ← ليلة القبة.

## التصدير

- **صورة PNG** للمشهد الحالي مع أسماء المناطق وشريط بيانات وإسناد مصدر الصور.
- **GeoJSON**: الحد الخارجي، المناطق التسع، الأرض المفتوحة، شبكة الطرق، حلقة المشي، نقاط الإطلالة، والنقطة المرجعية المعطاة.
- **JSON** لبيانات المناطق ومساحاتها وبرامجها.

## البناء والفحص

```bash
npm test          # فحوص بلا شبكة: البيانات، الإسناد الجغرافي، التصدير، وسلامة الملفات
npm run data      # يعيد توليد project-data.json و site-boundary.geojson من مصدر التطبيق
npm run build     # يدمج كل شيء في dist/index.html كملف واحد مكتفٍ بذاته
npm run smoke     # فحص متصفح اختياري بلقطات (يحتاج Playwright)
```

## الافتراضات التي لم تُؤكد بعد

- **الوحدة**: الطلب الأصلي قال «1500 كم»؛ النموذج مبني على **1500 مترًا** لكل ضلع (2,250,000 م²).
- **التضاريس**: الجبل والكثبان **شكل تمثيلي** بُني على وصف الملف، وليس نموذج ارتفاعات مقاسًا.
- **موضع النقطة**: تُعامل الإحداثيات كالركن الجنوبي الغربي، ويمكن جعلها المركز من نافذة الإعدادات.
- **شكل الأرض**: مربع محاذٍ للشرق والشمال — لا مضلع ملكية ولا رفع مساحي.
- **المدخل**: البوابة مفترضة على الحافة الجنوبية؛ الارتباط بالطريق العام يحتاج تأكيدًا.
- **بنود الملف غير الواضحة**: سطر `B=C C=C B=G` والرقم `24` و«منطقة أطفال ووش» — موضحة في `PROJECT_CONTEXT.md`.

الأرقام المنقولة من الملف (رسوم 10 ريال، 1000 موقف، 100 موقف VIP، ممر 100 متر) تظهر بنصها ومصدرها.
أما التوزيع والمقاسات والتضاريس فمقترحات تصميمية. لا موعد افتتاح ولا أسعار خدمات في هذا العرض.

## النشر

انشر **`dist/index.html` فقط** بعد `npm run build`. لا تنشر مجلد `reference/` الذي يحتوي على الخطة التسويقية؛
خادم المعاينة المحلي يمنعه أصلًا (403).

## بنية الملفات

```
index.html            الواجهة والهيكل
assets/app.css        التنسيق (عربي RTL، لوحة داكنة)
src/data.js           نموذج البيانات: الموقع، المناطق الست، التضاريس، الطرق، الجولة
src/terrain.js        حقل الارتفاعات: الجبل والكثبان والمساحات المسوّاة
src/geo.js            Vincenty على WGS 84، المساحات، تصدير GeoJSON
src/textures.js       خامات مولّدة برمجيًا (رمل، قماش، خشب، حصى) وبديل الصور الجوية
src/props.js          مكتبة المنشآت بمقاسات حقيقية (محطة وقود، بوابة، فود تراك، اسطبل، قبة 6 م، خيمة 5×7 م…)
src/assets.js         أشخاص ومركبات وسحاب وتجهيزات طرق وإنارة — كلها مولّدة برمجيًا
src/content.js        محتوى كل منطقة وتوزيعها
src/world.js          المشهد: تضاريس، سماء وشمس، ظلال، نبات، طرق تتبع الأرض
src/basemap.js        بلاطات الخرائط وفرشها على الأرض
src/mapview.js        عرض الخريطة ثنائي الأبعاد
src/controls.js       منظومة الكاميرا (تدوير، تحريك، تكبير نحو المؤشر، طيران)
src/app.js            الحالة والواجهة والتصدير
vendor/three.js       محرك العرض three.js r186 مدمج محليًا (MIT)
tools/                خادم محلي، فحص، بناء، تصدير بيانات، فحص متصفح
legacy/v1-index.html  النسخة السابقة (Canvas ثنائي الأبعاد) للمقارنة فقط
reference/            الخطة التسويقية — مرجع للفهم، لا يُنشر
```

## المصادر والحقوق

- صور الأقمار الصناعية: [Esri World Imagery](https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9) — تُطلب البلاطات المرئية فقط، بلا تخزين أو تنزيل بالجملة.
- خريطة الشوارع: [OpenStreetMap](https://www.openstreetmap.org/copyright) وفق [سياسة البلاطات](https://operations.osmfoundation.org/policies/tiles/).
- محرك العرض: [three.js](https://threejs.org) رخصة MIT، والتظليل المحيطي [n8ao](https://github.com/N8python/n8ao) رخصة ISC — كلاهما مدمج في `vendor/three.js`.
- لا نماذج ثلاثية الأبعاد خارجية: كل الأصول مولّدة برمجيًا داخل المشروع.
- الإسناد ظاهر دائمًا داخل التطبيق وفي صور التصدير.
